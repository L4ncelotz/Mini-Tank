# Mini Tank Duel — Mandatory Workflow

Never finish an implementation task without doing all applicable steps below.

1. Keep OMP Todo synchronized with the current work.
2. Keep `TASKS.md` synchronized with actual repository state.
3. Never mark unfinished work as complete.
4. Run typecheck and production build before completing a phase.
5. Fix errors introduced by the current work before continuing.
6. Review `git diff` before committing.
7. Commit completed, verified work.
8. Push the current branch after a successful commit.
9. If commit or push fails, report the failure instead of claiming success.
10. Do not implement future phases unless the user explicitly requests them.

`TASKS.md` is the durable project progress record.

OMP Todo is the active-session execution checklist.
